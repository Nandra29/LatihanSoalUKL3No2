# LatihanSoalUKL3No2
Fungsi Utama:Program ini berfungsi untuk menjumlahkan dua buah matriks yang memiliki ukuran baris dan kolom yang sama, di mana semua angka (elemen) matriks dimasukkan oleh user.
Cara Kerja: Program meminta user menentukan ukuran matriks (jumlah baris dan kolom),Program meminta user memasukkan semua angka untuk Matriks 1 dan Matriks 2 secara berurutan,Program menggunakan perulangan bersarang untuk menjumlahkan elemen-elemen dari Matriks 1 dan Matriks 2 yang berada pada posisi yang sama,dan hasil penjumlahan tersebut disimpan dalam matriks Hasil dan kemudian ditampilkan dalam format tabel.
